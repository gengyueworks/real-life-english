# Real Work English

> **Backup note (English)**: This directory is a backed-up copy of the open-source skill [richfemale7/real-work-english](https://github.com/richfemale7/real-work-english) (MIT). It turns your real work materials (resumes, meeting notes, project records, emails) into a 4–8 chapter workplace-English training pack — 20 minutes per chapter. For installation and usage, see [来源说明](来源说明.md) (source note) or install the upstream repo directly. The original repository remains the source of truth.

> 把你的真实工作材料，变成一套可以反复练习的职场英语训练包。

Real Work English 是一个面向真实职场场景的 Skill。它会根据你的岗位、沟通对象和项目材料，逐步制作四至八章英语训练内容，帮助你练习主持会议、客户沟通、方案讨论、向上汇报、资源谈判和业务面试。

| 你提供什么 | Skill 帮你做什么 | 你会得到什么 |
| --- | --- | --- |
| 一份岗位材料和一份真实项目或会议材料 | 理解你的职责、权限、沟通对象和高频英语场景 | 业务画像、四至八章学习地图和第一章样章 |
| 样章反馈和后续按需补充的材料 | 校准英语难度、对话自然度和冲突沟通风格 | 可以跟读的英文对话、三轮模拟加压和观点表达练习 |

第一次使用只需要准备两份材料，不需要一次提交全部工作资料。

## 3 分钟看懂怎么用

```mermaid
flowchart LR
    A[安装 Skill] --> B[提供两份材料]
    B --> C[确认业务画像]
    C --> D[确认章节地图]
    D --> E[生成一章样章]
    E --> F[反馈并逐章继续]
```

| 步骤 | 你需要做什么 | Skill 会返回什么 |
| --- | --- | --- |
| 1. 安装 | 把仓库安装到 Codex | 可以在对话中调用的 `$real-work-english` |
| 2. 提供材料 | 上传文件，或告诉 Codex 文件的准确路径 | 对岗位、职责、沟通对象和英语目标的初步理解 |
| 3. 确认画像 | 补充或纠正事实、权限和高频场景 | 一份经过你确认的业务画像 |
| 4. 确认地图 | 选择、删除或调整建议章节 | 四至八章训练顺序和每章目标 |
| 5. 检查样章 | 反馈事实、难度、自然度和沟通风格 | 第一章完整训练内容 |
| 6. 逐章继续 | 按需要补充材料，每次确认一章 | 持续校准的个人职场英语训练包 |

整个过程会分阶段推进。Skill 不会在你确认业务画像和章节地图之前批量生成全部章节。

## 新手使用说明：怎么下载和安装

### 方式 A：直接让 Codex 安装

把下面这段话复制到 Codex：

```text
请帮我安装这个 GitHub Skill：
https://github.com/richfemale7/real-work-english

请保留完整仓库内容，并告诉我安装是否成功。
```

安装完成后，在下一轮对话中使用 `$real-work-english` 开始。若 Codex 提示需要重新打开应用或新建对话，请按提示操作。

### 方式 B：使用安装命令

在终端中运行：

```bash
npx skills add richfemale7/real-work-english
```

完成后，重新打开 Codex 或开始一轮新对话，再调用 `$real-work-english`。

## 第一次使用，照着做

你可以把资料直接上传到对话，也可以把资料放在当前工作区，再写出文件的准确路径。Codex 只会读取你明确提供或指定的材料。

### 场景一：从零定制完整训练包

```text
使用 $real-work-english，根据我的真实工作资料，逐步制作一套职场英语训练包。

我的岗位材料：<上传简历或岗位介绍，或填写文件路径>
我的项目材料：<上传一份代表性项目材料或会议记录，或填写文件路径>

请先从最小画像开始。如果还缺少必要信息，请分批问我，不要一次让我填写长问卷。
读取材料后，请先复述你对我的岗位、职责、权限、沟通对象、高频英语场景和学习目标的理解，区分已确认事实、候选判断和待确认信息，等我确认后再规划章节。
```

接下来，Skill 会先建立业务画像。你确认画像后，它才会提出四至八章的章节地图；章节地图确认后，它只制作第一章样章。

### 场景二：先把一场真实会议做成样章

```text
使用 $real-work-english，根据这场真实会议制作一章英语训练内容。

我的岗位或职责说明：<上传材料，或填写文件路径>
会议记录或逐字稿：<上传材料，或填写文件路径>

请先复述你对会议背景、沟通对象、会议目标、已发生的分歧和我的权限边界的理解。把缺少的信息标记为【待确认信息】，等我确认后再提出这一章的训练设计。不要自行补全客户立场、价格、预算、库存、渠道能力或合作结果。
```

接下来，Skill 会先和你确认业务背景及训练方向，再制作包含完整对话、三轮模拟加压和观点表达练习的样章。

### 场景三：已有样章，继续下一章

```text
使用 $real-work-english，继续制作已确认章节地图中的下一章。

已确认的业务画像：<填写当前对话中的版本，或提供文件路径>
已确认的章节地图：<填写当前对话中的版本，或提供文件路径>
上一章内容：<填写当前对话中的版本，或提供文件路径>
我对上一章的反馈：<填写事实准确度、英语难度、对话自然度、冲突风格和篇幅反馈>
本章新增材料：<没有可以写“无”，有则上传或填写文件路径>

请先说明上一章反馈会怎样影响本章，再只制作下一章。资料不足时请标记缺口，不要用通用常识替代真实业务事实。
```

接下来，Skill 会先吸收上一章反馈，检查新增材料是否影响业务画像或章节地图，然后只推进下一章。

## 你需要提供什么，会得到什么

| 阶段 | 你需要提供 | 你会得到 | 需要你确认 |
| --- | --- | --- | --- |
| 第一次开始 | 简历、岗位介绍或职责说明；一份代表性项目材料或会议记录 | 最小业务画像 | 岗位事实、权限边界、高频场景和英语目标 |
| 画像确认后 | 对画像的补充和纠正 | 四至八章章节地图 | 章节顺序、训练目标、材料来源和冲突方向 |
| 第一章样章 | 已确认画像和章节地图 | 一章完整训练内容 | 事实准确度、难度、自然度、冲突风格和训练负担 |
| 后续逐章 | 样章反馈；按缺口补充周报、逐字稿、邮件、聊天或方案 | 经过持续校准的后续章节 | 每章内容和新增业务事实 |

每章固定包含四个板块：

1. **真实背景**：说明会议对象、业务问题和岗位权限。
2. **完整英文对话**：一段可以直接跟读的750至850词商务对话。
3. **三轮模拟加压**：练习在真实冲突中表达事实、风险、边界和解决方案。
4. **Opinion Presentation Practice**：独立表达一个与本章经历直接相关的业务问题。

每章还会增加三至五个高频专业表达。对话中约20%至30%的内容会保留真实业务中的分歧、条件交换或信息缺口。

安装前可以先查看完整公开样章：[和代理确认新品上市方案](references/article-reference.md)。这份样章用于展示章节结构、训练方式和表达质量，你自己的内容仍会以你提供的真实材料为基础。

## 适合什么时候使用

- 你需要主持英文会议，或在会议中表达完整观点。
- 你需要和海外客户、代理商、经销商或供应商讨论方案。
- 你可以完成简单沟通，遇到追问、分歧或长回答时容易卡住。
- 你希望用真实项目准备英文业务面试。
- 你想逐步建立一套可以持续迭代的个人职场英语资料。

这套 Skill 专注于用户实际需要完成的工作，包括讲清项目、回应分歧、推动下一步和处理资源边界。训练内容不会脱离用户材料扩展成通用商务英语课程。

## 它怎样工作

1. **建立最小画像**：确认岗位、行业、职责、沟通对象、英语水平、学习目标和冲突沟通偏好。
2. **识别高频场景**：当用户暂时说不清场景时，提出三至五个`【场景候选】`，等待用户选择、删除或补充。
3. **复述业务画像**：区分已确认事实、岗位权限、真实冲突、不透明信息和待确认事项。
4. **规划四至八章**：按照使用频率、重要性、现有语料和未来岗位目标安排顺序。
5. **先做一章样章**：校准业务准确度、英语难度、对话自然度和训练负担。
6. **逐章推进**：每次只制作一章，根据用户反馈继续调整。

## 事实与隐私

Skill 会区分以下内容：

- `【真实业务事实】`
- `【真实原话】`
- `【整理英文】`
- `【模拟训练】`
- `【待确认信息】`
- `【场景候选】`

业务逻辑必须来自用户材料。材料不足时，Skill 会提问或标记待确认信息，不会自行补全市场阶段、客户立场、价格、预算、库存、渠道能力、商业承诺或合作结果。

原始业务资料保留在用户自己的项目中。Skill 只读取用户提供或指定的资料，不会要求用户把原始文件复制进 Skill 目录，也不会修改原始文件。

需要公开分享时，可以把国家改为 `Market A/B/C`，人物改为岗位称呼，公司改为业务角色，产品改为通用代号。匿名化只改变识别信息，市场阶段、合作关系、权限边界和利益冲突仍会保留。
