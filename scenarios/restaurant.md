# 餐厅 Restaurant

> 这个场景你会在哪用到：进店、点餐、说忌口、买单——和服务员、同伴沟通吃饭这件事。

## 常用词

| 中文 | 英文 | 场景例句 |
| --- | --- | --- |
| 菜单 | **menu** | "Could I see the menu, please?"（请把菜单给我看看好吗？） |
| 点餐 | **order** | "I'd like to order the grilled salmon."（我想点烤三文鱼。） |
| 推荐 | **recommend** | "What do you recommend?"（你推荐什么？） |
| 招牌菜 | **signature dish** | "What's your signature dish?"（你们的招牌菜是什么？） |
| 三分熟 | **rare** | "I'll have the steak rare."（牛排我要三分熟。） |
| 五分熟 | **medium-rare** | "Medium-rare, please."（五分熟，谢谢。） |
| 全熟 | **well-done** | "Make sure it's well-done."（一定要全熟。） |
| 忌口 / 过敏 | **allergic** | "I'm allergic to peanuts."（我对花生过敏。） |
| 打包 | **take it to go** | "I'll take it to go."（这个我打包带走。） |
| 打包盒 | **doggy bag** | "Could I get a box to take this home?"（能给我个盒把这打包吗？） |
| 小费 | **tip** | "Is the tip included?"（小费包含在内了吗？） |
| 买单 / 结账 | **the bill / the check** | "Could we get the bill, please?"（麻烦买单。） |
| 白开水 / 自来水 | **tap water** | "Just tap water, thanks."（白开水就好，谢谢。） |
| 分单 | **separate checks** | "Can we pay separately?"（我们能分开付吗？） |
| 素食 | **vegetarian** | "Is this vegetarian?"（这是素的不？） |
| 辣 | **spicy** | "Is it very spicy?"（这个很辣吗？） |
| 前菜 | **starter / appetizer** | "I'll start with the soup."（我先来个汤。） |
| 续杯 | **refill** | "Could I get a refill on coffee?"（咖啡能续杯吗？） |
| 预订 | **reservation** | "I have a reservation under Smith."（我订了位，姓 Smith。） |

## 常用句

- "Do you have a table for two?"（两位有空桌吗？）
- "Could we sit by the window?"（我们能坐靠窗吗？）
- "What's today's special?"（今天有什么特色菜？）
- "No onions, please."（请不要放洋葱。）
