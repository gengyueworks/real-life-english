# 中文版 · 外国人来中国（zh/）

给你——一个英文母语者，来到中国、想在这儿真的开口说话的人。

你知道英文意思，这里帮你把它变成**能直接说出口的中文**，再配一句真实场景的中文例句（带英文翻译）。

## 怎么用

1. 找到你要的场景（下面清单）。
2. 每行：`英文 | 中文 | 场景例句（中文 + 英文翻译）`。
3. 扫一眼 emoji 图标，快速定位你要的词。

## 格式

- 列顺序：`英文 | 中文 | 场景例句（中文 + 英文翻译）`
- 中文词用 **粗体**
- 例句：中文句 + （英文翻译），保持口语、真实
- 有清晰对应的词可在最左加 emoji 图标列

> 反向版本在 `../en/`：给出国的中国人，按中文查英文。两边场景同名、列顺序相反。
