# 真实场景双语词汇 · Real-Life Words

把「日常生活 / 出国里真用得上的词」按场景整理成册，**双向、可查、实用**。

不是考试英语，不是背单词 App。这里的每一个词都配一句**真实场景里的用法**——你真的会开口说的那句话。

## 这是双向的（重点）

同一个场景，两套列顺序，给两类人用：

- **`en/` — 中文使用者出国**：你知道中文意思，想学会用英文怎么说。列顺序：`中文 | 英文 | 场景例句（英文 + 中文翻译）`。
- **`zh/` — 外国人来中国**：他知道英文，想查中文怎么说。列顺序反过来：`英文 | 中文 | 场景例句（中文 + 英文翻译）`。

两边场景一一对应，可以对照着学，也能各自独立查。

## 首要定位：实用、好查

- **实用**：例句必须是在该场景里真的会说的，不编造书面语。
- **好查**：按「你会在哪用到」组织场景，而不是按字母排序；表格 + emoji 图标，扫一眼就能定位。

## 设计原则

1. **真实优先**：例句是在该场景里真的会说的，不写教科书式句子。
2. **场景优先**：按「你会在哪用到」组织，而非字母顺序。
3. **双向对称**：`en/` 与 `zh/` 场景同名、列顺序相反，方便对照。
4. **图标列可选**：表格最左可加一列 emoji 当图标（GitHub 原生渲染，不依赖图片）；有清晰对应的词就加，没有就省略整列（如水果大多无对应 emoji）。
5. **可扩展**：任何人都能提 PR 补词、补场景、改例句。
