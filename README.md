# 真实场景英语 · Real-Life English

把「出国 / 日常生活里真用得上的词」按场景整理成册。

不是考试英语，不是背单词 App。这里的每一个词都配一句**真实场景里的用法**——你在水果摊、餐厅、机场、医院、超市、健身房会真的说出来的那句话。

> 灵感来源：一条把「水果英语」整理成卡片的小红书笔记。那种「终于整理好了」的爽感，和按场景归类的方式，就是本仓库想系统化的东西。

## 这个专题是什么

- **类型**：实用场景口语词（practical scenario vocabulary）
- **每条格式**：中文释义 + 英文 + 场景例句（带中文翻译，方便确认意思）
- **组织方式**：按场景分文件，每个场景一个 `.md`

## 设计原则

1. **真实优先**：例句必须是在该场景里真的会说的，不编造书面语。
2. **场景优先**：按「你会在哪用到」组织，而不是按字母顺序。
3. **可扩展**：任何人都能提 PR 补词、补场景、改例句。
