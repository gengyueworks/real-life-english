# 超市 / 买菜 Supermarket & Grocery

> 这个场景你会在哪用到：推车、找货架、看保质期、称重、结账、退货——日常采买的全过程。

## 常用词

| 中文 | 英文 | 场景例句 |
| --- | --- | --- |
| 购物车 | **cart** | "Could I grab a cart?"（我推个购物车。） |
| 货架 | **shelf** | "It's on the top shelf."（在最上层货架上。） |
| 生鲜区 | **produce** | "The produce section is in the back."（生鲜区在后面。） |
| 打折 / 特价 | **on sale** | "Is this on sale this week?"（这周这个特价吗？） |
| 保质期 | **expiration date** | "Check the expiration date."（看看保质期。） |
| 称重 | **weigh** | "You weigh veggies at that scale."（菜在那台秤上称。） |
| 结账 | **checkout** | "Which checkout line is shortest?"（哪条结账队最短？） |
| 自助结账 | **self-checkout** | "I'll use the self-checkout."（我用自助结账。） |
| 会员卡 | **loyalty card** | "Do you have a loyalty card?"（你有会员卡吗？） |
| 收据 | **receipt** | "Keep your receipt."（收据收好。） |
| 退货 | **return** | "Can I return this?"（这个能退吗？） |
| 有机 | **organic** | "Is this organic?"（这是有机的吗？） |
| 临期降价 | **marked down** | "These are marked down."（这些降价处理了。） |
| 散装 | **bulk** | "The bulk bins are over there."（散装柜在那边。） |
| 冷冻区 | **frozen aisle** | "It's in the frozen aisle."（在冷冻那排。） |

## 常用句

- "Where can I find the eggs?"（鸡蛋在哪？）
- "Do you have a bigger size?"（有大包装的吗？）
- "I think this was scanned twice."（这个好像扫了两次。）
- "Is the plastic bag charged?"（塑料袋要收费吗？）
