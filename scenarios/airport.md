# 机场 / 出行 Airport & Travel

> 这个场景你会在哪用到：出发值机、过安检、找登机口、转机、入境、拿行李——一路上和机场人员、海关的沟通。

## 常用词

| 中文 | 英文 | 场景例句 |
| --- | --- | --- |
| 登机牌 | **boarding pass** | "Where can I get my boarding pass?"（在哪拿登机牌？） |
| 值机 | **check in** | "I'd like to check in for my flight."（我要办登机手续。） |
| 托运行李 | **checked baggage** | "I need to check this bag."（这件要托运。） |
| 随身行李 | **carry-on** | "Is this okay as a carry-on?"（这个能随身带吗？） |
| 安检 | **security** | "Security is right after this hall."（安检就在这个大厅后面。） |
| 登机口 | **gate** | "What's the gate for flight 123?"（123 航班几号登机口？） |
| 延误 | **delayed** | "My flight is delayed."（我的航班延误了。） |
| 取消 | **cancelled** | "The flight was cancelled."（航班取消了。） |
| 转机 | **layover / connecting flight** | "I have a two-hour layover."（我有两个小时转机时间。） |
| 入境 | **immigration** | "Immigration is on the lower level."（入境处在下层。） |
| 海关 | **customs** | "Nothing to declare."（没有要申报的。） |
| 行李转盘 | **baggage claim** | "Which carousel is for my flight?"（我航班行李在哪个转盘？） |
| 护照 | **passport** | "May I see your passport?"（请出示护照。） |
| 签证 | **visa** | "Do I need a visa for this stay?"（这次停留需要签证吗？） |
| 免税店 | **duty-free** | "Duty-free is past security."（免税店在安检里侧。） |
| 靠窗座位 | **window seat** | "Could I get a window seat?"（能给我靠窗的座位吗？） |
| 过道座位 | **aisle seat** | "An aisle seat is easier for me."（过道座对我更方便。） |

## 常用句

- "Is this flight on time?"（这班飞机准点吗？）
- "Where do I pick up my checked bag?"（托运行李在哪取？）
- "My luggage didn't arrive."（我的行李没到。）
- "How do I get to the transit hotel?"（去转机酒店怎么走？）
