# 英文版 · 中文使用者出国（en/）

给你——一个中文母语者，要去英语国家、想在那儿真的开口说话的人。

你知道中文意思，这里帮你把它变成**能直接说出口的英文**，再配一句真实场景例句。

## 怎么用

1. 找到你要的场景（下面清单）。
2. 每行：`中文 | 英文 | 场景例句（英文 + 中文翻译）`。
3. 扫一眼 emoji 图标，快速定位你要的词。

## 格式

- 列顺序：`中文 | 英文 | 场景例句`
- 英文词用 **粗体**
- 例句：英文句 + （中文翻译），保持口语、真实
- 有清晰对应的词可在最左加 emoji 图标列

> 反向版本在 `../zh/`：给来中国的外国人，按英文查中文。两边场景同名、列顺序相反。
